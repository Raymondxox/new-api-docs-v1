---
title: 订阅管理
description: 创建、发布和维护订阅套餐，并查看用户订阅状态。
---

访问 `/subscriptions` 管理订阅套餐。

## 创建套餐

点击「创建套餐」，设置标题、副标题、价格、总额度、有效期、额度重置周期、排序、购买上限、启用状态、余额购买、钱包溢出回退、升级/降级分组和支付产品映射。额度为 0 表示不限总额度。

## 发布和下架

启用套餐后，符合条件的用户会在钱包中看到并可购买；停用后不再接受新购买。已有用户订阅会保留自己的状态、到期时间和套餐快照，不会因为套餐停用自动取消。

## 用户订阅

打开套餐行操作可查看用户订阅。管理员可以：

- 为用户手动创建订阅
- 按用户和套餐重置额度
- 按整个套餐批量重置额度，并选择是否推进下次重置时间
- 立即使订阅失效，将状态设为 `cancelled` 并结束权益
- 永久删除订阅记录

## 计费注意事项

用户可以选择优先订阅、优先钱包、仅用订阅或仅用钱包。套餐还可控制订阅额度耗尽后是否允许回退钱包。当前 New API 没有支付平台自动续费事件处理，支付产品应按一次性购买配置；修改套餐前先确认现有订阅不会产生意外变化。
