系统设置入口为 `/system-settings/site`，仅 Root 可访问。左侧使用嵌套工作区：先选择设置域，再选择具体分区；进入后可使用「返回控制台」回到主导航。

## 七大设置域

| 设置域 | 主要内容 |
| --- | --- |
| 站点与品牌 | 系统信息、公告、内置顶部导航开关、侧边栏模块开关 |
| 身份验证 | 基础认证、OAuth、Passkey、机器人防护、自定义 OAuth |
| 计费与支付 | 额度、货币、模型价格、分组价格、支付网关、签到奖励 |
| 模型与路由 | 全局模型、路由可靠性、Gemini/Claude/Grok、渠道亲和、部署 |
| 安全与限制 | 速率限制、敏感词、SSRF、Token 限制 |
| 控制台内容 | 数据看板、公告、API 信息、FAQ、Uptime Kuma、聊天客户端预设、绘图 |
| 运维 | 系统行为、监控告警、SMTP、Worker、数据库/文件日志维护、性能、更新检查 |

## 修改设置

1. 进入对应设置域和具体页面。
2. 修改字段并确认字段说明、默认值和影响范围。
3. 点击保存，等待成功提示。
4. 使用普通用户、Admin 和 Root 角色分别检查受影响页面；涉及支付、认证、SSRF 或计费时先在测试实例验证。

## 备份与回滚

设置通常以系统选项保存。生产环境修改前应记录原值并准备回滚；涉及支付、认证、SSRF 和计费的变更应先在测试实例验证。页面保存成功只表示选项写入成功，不代表外部支付、SMTP 或 Worker 已经连通。
