---

系统设置地址为 `/system-settings/site`，仅 Root 可访问。左侧采用嵌套导航，先选择设置域，再选择具体设置项。

## 七大设置域

| 设置域 | 主要内容 |
| --- | --- |
| 站点与品牌 | 系统信息、公告、顶部导航、侧边栏模块 |
| 身份验证 | 密码、注册、OAuth、Passkey、机器人防护 |
| 计费与支付 | 额度、货币、价格、分组、支付、签到 |
| 模型与路由 | 全局模型、可靠性、供应商适配、渠道亲和、部署 |
| 安全与限制 | 限流、敏感词、SSRF、Token 上限 |
| 控制台内容 | 看板、公告、API 信息、FAQ、聊天预设、绘图 |
| 运维 | 系统行为、监控、SMTP、Worker、日志、性能、更新 |

## 修改设置

1. 进入对应设置域和具体页面。
2. 修改字段并确认字段说明、默认值和影响范围。
3. 点击保存，等待成功提示。
4. 使用普通用户、Admin 和 Root 角色分别检查受影响页面。

## 备份与回滚

设置通常以系统选项保存。生产环境修改前应记录原值，涉及支付、认证、SSRF 和计费的变更应先在测试实例验证。
