访问 `/system-settings/content` 管理控制台内容。

## 数据看板

配置数据看板开关、刷新间隔和默认时间粒度；后端数据仍按小时聚合，默认粒度只是界面展示选择。数据看板本身仍按角色隐藏用户分析等管理分区。

## 公告、API 信息与 FAQ

分别控制公告、API 地址说明和 FAQ 的启用状态及内容。未启用的卡片不会在概览页显示。

## Uptime Kuma

配置 Uptime Kuma 监控分组或状态来源，在概览页展示运行时间状态；外部 Uptime Kuma 服务不可用时，卡片可能显示错误或无数据。

## 聊天预设

维护聊天客户端预设数组。每项由客户端名称和 URL 模板组成，可使用网页链接、自定义协议或 FluentRead 集成，并可通过 `{address}`、`{key}`、`{cherryConfig}`、`{aionuiConfig}`、`{deepchatConfig}` 注入实例地址或 API 密钥。预设会出现在用户侧边栏和 API 密钥行菜单中。

<Callout type="warn">
  带密钥占位符的预设会把用户完整 API 密钥交给目标网页、应用或扩展。只配置可信目标，避免把密钥放入会被第三方日志、浏览器历史或分析脚本采集的 URL。
</Callout>

## 绘图

配置绘图功能开关及 Midjourney 相关通知、账号过滤、转发和成功检查行为。关闭绘图展示不会替代渠道侧对绘图接口的权限和可用性控制。
