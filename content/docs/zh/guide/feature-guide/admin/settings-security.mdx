import { Callout } from 'fumadocs-ui/components/callout';

访问 `/system-settings/security` 管理安全与限制。

## 速率限制

按模型请求设置请求次数、成功次数、时间窗口和分组范围，防止单个用户或分组过度占用资源。

## 敏感词

配置输入内容和提示词的敏感词检查，以及敏感词列表。

## SSRF 防护

控制服务端抓取外部地址时的私有 IP、域名、端口和 IP 过滤策略。默认应保持防护开启，并只对白名单目标开放访问。

## Token 限制

设置用户可创建或持有的 Token 数量上限，避免凭证无限增长。

<Callout type="warn">
  SSRF、限流和敏感词配置可能影响所有用户的请求。修改后请使用测试渠道验证正常 API、图片和文件请求。
</Callout>
