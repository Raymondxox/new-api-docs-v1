访问 `/system-settings/security` 管理安全与限制。

## 速率限制

按用户、分组、模型或请求维度设置请求次数、成功次数和时间窗口，防止单个主体过度占用资源。命中限制时 API 请求会被拒绝或延迟，具体响应取决于限流中间件。

## 敏感词

配置输入内容和提示词的敏感词检查，以及敏感词列表。规则可能影响聊天、补全和其他可检查的请求格式。

## SSRF 防护

控制服务端抓取外部地址时的私有 IP、域名、端口和 IP 过滤策略。修改后会影响图片、文件和供应商请求等需要服务端访问 URL 的功能；应优先保持防护开启并使用明确白名单。

## Token 限制

设置用户可创建或持有的 Token 数量上限，避免凭证无限增长。API 密钥的额度、模型和 IP 限制仍在用户自己的 API 密钥编辑器中配置。

<Callout type="warn">
  SSRF、限流和敏感词配置可能影响所有用户的请求。修改后请使用测试渠道验证正常 API、图片和文件请求。
</Callout>
