系统信息页是 Root 专属页面，地址为 `/system-info`。页面包含“实例”和“系统任务”两个区域。

## 实例

实例表展示已向当前系统报告状态的节点。

### 查看实例状态

- 在线状态和最近心跳
- 节点名称、主节点/工作节点角色、版本和运行时
- CPU、内存和存储使用情况
- 启动时间和最后上报时间

### 管理失效实例

对于超过后端失效阈值、状态为 `stale` 的实例，Root 可以删除单条记录或批量删除全部失效记录。接口会再次检查实例仍为失效状态；节点重新上报后会重新出现在列表中。多实例部署应为每个节点设置稳定且唯一的 `NODE_NAME`。

## 系统任务

系统任务区域显示调度器创建的跨实例维护任务。当前实现包含消费日志清理、批量渠道测试、批量上游模型更新、绘图任务轮询和异步任务轮询等类型；没有待处理工作时，部分轮询任务不会创建记录。

### 任务状态

- `pending`：等待执行
- `running`：正在执行
- `succeeded`：执行成功
- `failed`：执行失败
- `cancelled`：任务被取消或失去执行资格

页面展示任务进度、执行器、更新时间和错误详情。运行中的任务会每 8 秒自动刷新，没有活动任务时自动刷新会暂停。
