系统信息页是 Root 专属页面，地址为 `/system-info`。页面包含“实例”和“系统任务”两个区域。

## 实例

实例表展示已向当前系统报告状态的节点。

### 查看实例状态

- 在线状态和最近心跳
- 节点角色、版本和运行时
- CPU、内存和存储使用情况
- 启动时间和最后上报时间

### 管理失效实例

对于长时间未上报的实例，Root 可以删除单个失效实例或批量删除全部失效实例。删除前应确认节点确实已经下线，避免误删仍在恢复中的节点。

## 系统任务

系统任务区域显示跨实例执行的维护任务，包括日志清理、批量渠道测试、批量上游模型更新、绘图任务轮询和异步任务轮询。

### 任务状态

- `pending`：等待执行
- `running`：正在执行
- `succeeded`：执行成功
- `failed`：执行失败

页面展示任务进度、执行器、更新时间和错误详情。运行中的任务会每 8 秒自动刷新，没有活动任务时自动刷新会暂停。
