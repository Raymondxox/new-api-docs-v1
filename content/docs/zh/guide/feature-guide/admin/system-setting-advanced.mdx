旧版本把支付、限流、倍率、聊天、绘图、看板和模型集中在一篇“高级配置”中。当前版本已按职责拆分为七个设置域，访问旧链接时请使用以下新页面。

## 对应关系

| 旧内容 | 当前页面 |
| --- | --- |
| 支付、充值、倍率 | [计费与支付](./settings-billing) |
| 限流和 Token | [安全与限制](./settings-security) |
| 模型和渠道可靠性 | [模型与路由](./settings-models) |
| 聊天、绘图、看板 | [控制台内容](./settings-content) |
| 邮件、日志、性能 | [运维](./settings-operations) |

请不要继续按照旧版“系统高级配置”菜单寻找字段；左侧系统管理导航显示的设置域和子页面才是当前版本的有效入口。
