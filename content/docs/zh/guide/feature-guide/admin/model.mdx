管理员从侧边栏“模型”进入 `/models/metadata`。页面有“元信息”和“部署”两个标签。

## 模型元信息

### 添加和编辑模型

点击「添加模型」创建模型元信息，或打开已有模型维护名称、供应商、状态、匹配类型、标签、端点、启用分组、配额类型和官方同步标记。模型名称是用户请求和定价页使用的标识，修改前请评估现有客户端和渠道映射。

### 同步上游元数据

「同步上游」向导可选择同步源并预览模型和供应商变更；「缺失模型」用于发现渠道已提供但元信息中缺少的模型。「预填充组」和「管理供应商」用于补充元数据关联。同步前应检查冲突和覆盖范围。

### 价格与分组

模型页面维护模型元信息及启用分组，价格、倍率、工具价格和分组倍率主要在「系统设置 → 计费与支付」维护。定价页会组合模型元信息和计费配置生成用户可见结果。

## 模型部署

如果 Root 未在“系统设置 → 模型与路由 → 模型部署”启用部署服务，部署标签会显示未启用状态。

启用后，管理员可以：

- 创建部署并选择提供商、地域和硬件等配置
- 查看部署状态、提供商、硬件、创建时间和剩余时间
- 查看部署详情、容器列表和单个容器的状态、区域、GPU 数量等信息
- 按容器选择标准输出/错误输出日志，刷新并下载日志
- 更新配置、续期、重命名或删除部署

<Callout type="warn">
  删除部署会影响正在使用该部署的渠道。执行前先确认模型路由已经切换到其他可用渠道。
</Callout>
