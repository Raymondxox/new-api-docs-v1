管理员从侧边栏“模型”进入 `/models/metadata`。页面有“元信息”和“部署”两个标签。

## 模型元信息

### 添加和编辑模型

点击“添加模型”创建模型元信息，或打开已有模型编辑名称、供应商、能力、公开状态、价格和分组。模型名称是用户请求时使用的标识，修改前请评估对现有客户端的影响。

### 同步上游元数据

使用官方同步功能从上游元数据源更新模型。同步前检查预览和冲突，确认不会覆盖本地价格、模型映射或特殊能力。

### 价格与分组

模型的输入、输出、缓存、图片、音频和工具价格，以及可用分组和倍率，最终在系统设置的计费域维护。模型页面负责模型级元信息，计费页面负责全局价格策略。

## 模型部署

如果 Root 未在“系统设置 → 模型与路由 → 模型部署”启用部署服务，部署标签会显示未启用状态。

启用后，管理员可以：

- 创建和编辑部署
- 选择硬件类型、地域和副本数量
- 查看部署状态和容器
- 查看部署日志
- 续期、重命名或删除部署

<Callout type="warn">
  删除部署会影响正在使用该部署的渠道。执行前先确认模型路由已经切换到其他可用渠道。
</Callout>
