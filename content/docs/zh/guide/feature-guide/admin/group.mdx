当前版本没有独立的“分组”侧边栏入口。分组由用户编辑、API 密钥编辑、渠道配置以及 Root 的“计费与支付 → 分组价格”共同维护。

## 分组作用

分组可以同时决定用户或 API 密钥可访问的渠道、模型、倍率和计费规则。渠道也可以配置允许的分组。

## 配置流程

1. 在「系统设置 → 计费与支付 → 分组价格」定义分组、倍率和全局 Auto 顺序。
2. 在渠道编辑器中设置渠道所属分组。
3. 在用户或 API 密钥编辑器中分配分组。
4. 用游乐场或 API 请求验证模型可见性和实际扣费。

## Auto 分组

API 密钥选择 `auto` 分组后，可以继承 Root 的全局顺序或保存密钥级自定义顺序。自定义模式必须至少选择一个分组；保存为空数组表示继承全局配置。开启跨分组重试后，当前分组的优先级层级耗尽时才会继续尝试下一个分组。

<Callout type="info">
  如果用户看不到某个模型，请依次检查模型公开状态、渠道模型列表、渠道分组、用户分组和 API 密钥模型限制。
</Callout>
