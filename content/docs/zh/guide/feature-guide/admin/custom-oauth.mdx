---
title: 自定义 OAuth
description: Root 在身份验证设置中配置自定义 OAuth/OIDC 登录提供商。
---

自定义 OAuth 位于 Root 的「系统设置 → 身份验证 → 自定义 OAuth」，地址为 `/system-settings/auth/custom-oauth`。它是身份验证设置的正式分区，不再使用旧版独立管理员入口。

## 添加提供商

1. 点击「添加 OAuth 提供商」。
2. 选择预设或填写显示名称、客户端 ID 和客户端密钥。
3. 使用发现功能，或手动填写授权、令牌和用户信息端点。
4. 配置 Scope，以及用户 ID、用户名和邮箱等字段映射。
5. 保存并启用后，在登录页和个人资料的账户绑定区验证完整流程。

## 回调地址

页面会根据当前公开地址显示回调 URL。将该地址原样登记到 OAuth 提供商后台。反向代理部署时，确认服务器地址与转发头正确，否则页面生成的回调地址可能不可达。

## 安全要求

- 生产环境使用 HTTPS，并限制客户端密钥访问。
- 只请求必要 Scope。
- 用户 ID 字段必须稳定且唯一，不能使用可能变更的昵称作为主体标识。
- 修改字段映射前检查已有账号绑定，避免生成重复身份。
- 删除或禁用提供商前，确认现有用户仍有其他登录方式。
