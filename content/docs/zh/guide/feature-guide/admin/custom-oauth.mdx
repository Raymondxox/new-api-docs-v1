---
title: 自定义 OAuth
description: 配置符合 OAuth/OIDC 规范的自定义登录提供商。
---

自定义 OAuth 现在位于 Root 的“系统设置 → 身份验证 → 自定义 OAuth”，地址为 `/system-settings/auth/custom-oauth`。管理员侧栏中的旧入口已合并到身份验证设置。

## 添加提供商

1. 点击“添加提供商”。
2. 填写显示名称、客户端 ID 和客户端密钥。
3. 填写 OIDC Discovery 地址，或分别填写授权、令牌和用户信息端点。
4. 保存并使用发现或测试功能验证配置。

## 回调地址

回调地址必须使用当前实例的公开 HTTPS 地址，并与 OAuth 提供商后台登记的地址完全一致。反向代理部署时，确认服务器地址设置和转发头正确。

## 安全要求

客户端密钥只保存在服务端；修改提供商后用测试账号验证登录、绑定和解绑流程。
