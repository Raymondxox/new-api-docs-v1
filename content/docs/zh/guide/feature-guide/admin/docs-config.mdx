当前版本不再把“文档配置”作为单独的系统设置域。相关能力分布在 Root 的“站点与品牌”和“控制台内容”中。

## 站点与品牌

配置站点名称、Logo、页脚、关于页面、首页内容、顶部导航和侧边栏模块。

## 控制台内容

配置公告、API 地址说明、FAQ、Uptime Kuma、聊天预设和绘图功能展示。

## 文档链接

顶部导航只控制「文档」入口是否显示；实际文档地址来自「计费与支付 → 额度设置」中的文档链接，留空时前端使用站内 `/docs`。修改后请用未登录、普通用户和管理员角色检查目标是否可访问。

- [控制台内容设置](./settings-content)
