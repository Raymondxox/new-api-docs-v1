---
title: 日志与数据分析
description: 查看全站 API、绘图、任务和操作日志，并分析平台用量。
---

管理员可以在「使用日志」中查看授权范围内的记录，在「数据看板」中查看聚合分析。日志读取范围由角色和管理员权限共同决定。

## 全站日志

访问 `/usage-logs/common`，按时间、用户、API 密钥、模型、渠道、状态和类型筛选。打开记录可查看请求、Token、耗时、扣费、错误和管理员信息；普通用户不会收到管理员专属字段。

## 绘图和任务日志

访问 `/usage-logs/drawing` 查看绘图任务，访问 `/usage-logs/task` 查看其他异步任务。任务最终状态可能晚于 HTTP 提交结果，排查时应查看任务记录而不是只看提交请求。

## 数据看板

在 `/dashboard/models` 查看模型调用分析、分流和用户统计。Root 和 Admin 的可见维度受角色和系统配置影响。

## 日志维护

Root 可在“系统设置 → 运维 → 日志维护”控制是否记录逐请求额度消费、按时间清理数据库日志，并按文件数或天数清理服务器日志文件。数据库清理以系统任务执行并展示进度。删除会影响审计、排行榜和数据分析，请在实施前备份或导出必要数据。
