title: 日志与数据分析
description: 查看全站 API、绘图、任务和操作日志，并分析平台用量。
---

管理员可以在“使用日志”中查看管理范围内的记录，在“数据看板”中查看聚合分析。

## 全站日志

访问 `/usage-logs/common`，切换“全部”或“仅自己”，按时间、用户、模型、渠道、状态和类型筛选。打开记录可查看请求、Token、耗时、扣费、错误和管理员信息。

## 绘图和任务日志

访问 `/usage-logs/task` 查看绘图和异步任务。任务的最终成功或失败状态可能晚于 HTTP 请求返回，排查时应查看任务详情。

## 数据看板

在 `/dashboard/models` 查看模型调用分析、分流和用户统计。Root 和 Admin 的可见维度受角色和系统配置影响。

## 日志维护

Root 可在“系统设置 → 运维 → 日志维护”控制消费日志维护。清理策略会影响审计和数据分析，请在实施前备份或导出必要数据。
