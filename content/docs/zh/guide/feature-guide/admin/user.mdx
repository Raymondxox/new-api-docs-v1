---
title: 用户管理
description: 管理用户账户、角色、分组、额度和第三方绑定。
---

访问 `/users` 查看用户列表。该页面要求 Admin 或更高角色。

## 搜索和筛选

按用户名、邮箱、ID、状态、角色或分组筛选。列表显示用户 ID、用户名、额度、分组、创建时间和最后登录时间。

## 创建和编辑用户

管理员可以创建用户，或打开用户行操作编辑：

- 用户名、邮箱和密码
- 启用/禁用状态
- 用户角色
- 用户分组
- 其他账户字段

Root 应谨慎授予 Admin 或 Root 角色；角色变更会立即影响菜单和接口权限。

## 调整额度

选择“增加”“扣减”或“覆盖”模式，输入额度并确认。调整前检查当前余额和计费单位，必要时在日志中记录业务原因。

## 绑定管理与删除

管理员可查看或维护用户的第三方绑定。删除用户会影响其 API 密钥、日志、订阅和会话，请先确认数据保留要求。
