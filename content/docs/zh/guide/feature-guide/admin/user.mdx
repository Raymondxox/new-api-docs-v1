title: 用户管理
description: 管理用户账户、角色、分组、额度和第三方绑定。
---

访问 `/users` 查看用户列表。该页面要求 Admin 或 Root；Root 可以进一步编辑 Admin 的权限覆盖。

## 搜索和筛选

按关键词、分组、角色和状态等条件筛选，并按页面支持的字段排序。列表展示用户标识、状态、角色、分组、额度及账户时间信息。

## 创建和编辑用户

管理员可以创建用户，或打开用户行操作编辑：

- 用户名、邮箱和密码
- 启用/禁用状态
- 用户角色
- 用户分组
- Admin 权限矩阵（仅 Root 编辑 Admin 时显示）

Admin 权限不是简单的“全有或全无”。以渠道为例，读取、操作、普通写入、敏感写入和查看密钥是不同动作；Root 可在默认 Admin 基线上逐项覆盖。角色或权限变更会立即影响菜单和接口操作。

## 调整额度

选择“增加”“扣减”或“覆盖”模式，输入额度并确认。调整前检查当前余额和计费单位，必要时在日志中记录业务原因。

## 绑定管理与删除

管理员可查看或清理用户的第三方绑定，并可强制关闭用户 2FA。删除或禁用用户会影响其登录、API 密钥、订阅和会话；Root 用户不能通过普通用户管理流程删除或降级。
