访问 `/system-settings/billing` 管理计费与支付。

## 额度设置

配置新用户额度、预扣额度、邀请奖励、充值入口和免费模型的预扣策略。额度计算还会受模型、分组和媒体/工具倍率影响。

## 货币与显示

设置额度单位、货币显示、美元换算、Token 统计和自定义货币符号。钱包、API 密钥、订阅和价格页会使用这里的显示规则。

## 模型价格

维护模型倍率、补全倍率、缓存倍率、图片/音频倍率、工具价格、按次计费和上游倍率同步。具体模型还可使用动态计费表达式。

## 分组价格

配置分组倍率、分组间倍率、用户可用分组、Auto 分组顺序和跨分组重试相关策略。用户和 API 密钥的分组限制还需分别在对应编辑器中配置。

## 支付网关

配置 EPay、Stripe、Creem、Waffo/Waffo Pancake 等实例启用的支付方式、回调地址、金额选项和支付产品映射。回调地址和密钥属于生产敏感配置，不能写入公开文档或截图。

## 签到奖励

启用签到奖励并设置每日奖励额度范围和相关规则。

<Callout type="warn">
  计费和支付设置会直接影响用户余额、价格和订单回调。修改前请先确认合规条款、回调地址和测试模式。
</Callout>
