访问 `/redemption-codes` 管理兑换码。

## 创建兑换码

1. 点击「创建代码」。
2. 设置名称、生成数量、额度和过期时间等表单字段。
3. 确认生成，在列表中复制单个或选中的兑换码。

完整兑换码只应发给目标用户。当前列表提供复制单个代码和复制选中代码，不提供独立 CSV 导出流程。

## 管理兑换码

列表可以查看代码、名称、状态、额度、创建时间、使用者和使用时间。行操作支持查看、编辑、启用/禁用和删除；「删除无效」会批量删除已使用、已禁用和已过期代码。

### 状态说明

- 未使用：可以兑换
- 已使用：已绑定用户，不可重复兑换
- 已禁用：管理员禁止继续使用
- 已过期：超过有效期

<Callout type="warn">
  兑换码相当于额度凭证。复制或分发后请控制内容访问范围，删除无效代码前确认没有待发放的批次。
</Callout>
