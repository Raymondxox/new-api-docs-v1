- 系统设置是 Root 专属的实例级配置工作区，可从侧边栏点击进入「系统设置」。<br/>本文用于说明各设置域的职责和通用操作方式。

## 设置域与分区

系统设置采用两级导航：先选择设置域，再选择具体分区。

| 设置域 | 路径与分区 | 主要职责 |
| --- | --- | --- |
| [站点与品牌](./settings-site) | `/system-settings/site`：<br/>系统信息、系统公告、顶部导航、侧边栏模块 | 站点身份、公开内容、法律文档和导航入口。 |
| [身份验证](./settings-auth) | `/system-settings/auth`：<br/>基本身份认证、OAuth集成、通行密钥认证、机器人保护、自定义 OAuth | 登录、注册、PassKey和 第三方OAuth。 |
| [计费与支付](./settings-billing) | `/system-settings/billing`：<br/>额度设置、货币与展示、模型定价、分组定价、支付网关、签到奖励 | 额度单位、价格、分组倍率、充值和签到。 |
| [模型与路由](./settings-models) | `/system-settings/models`：<br/>全局模型配置、路由可靠性、Gemini、Claude、Grok、渠道亲和性、模型部署 | 模型协议适配、重试与渠道选择策略。 |
| [安全与限制](./settings-security) | `/system-settings/security`：<br/>速率限制、敏感词、SSRF保护、令牌限制 | 请求频率、内容检查、外部资源访问和密钥数量限制。 |
| [控制台内容](./settings-content) | `/system-settings/content`：<br/>数据仪表板、公告、API 地址、常见问答、Uptime Kuma、聊天预设、绘图 | 控制台展示内容和部分客户端功能。 |
| [运维](./settings-operations) | `/system-settings/operations`：<br/>系统行为、监控与警报、SMTP邮箱、Worker代理、日志维护、性能、系统更新 | 运行行为、邮件、代理、维护与性能设置。 |

## 修改设置

1. 进入对应设置域和具体分区。
2. 修改字段，并核对页面说明、单位、格式和影响范围。
3. 保存后确认成功提示；同一表单包含多项修改时，还要检查各字段是否都已保存。
4. 刷新当前页面，并使用真正受影响的入口验证结果。
5. 涉及认证、支付、计费、SSRF 或对外回调时，先在测试实例或维护窗口验证。

## 保存与生效机制

系统设置通常以键值形式保存到数据库。配置写入成功后，当前进程会更新内存中的设置值。多实例部署中的其他进程按同步频率周期重新载入数据库选项，默认约为 60 秒。

<Callout type="info">
  - 页面显示“保存成功”只表示相应配置项已写入，不代表 OAuth、SMTP、支付网关、Webhook、Worker 或其他外部服务已经连通。
  - 必须通过实际登录、发信、支付沙箱、回调或业务请求进行验证。
</Callout>

## 敏感配置与日志

- 系统选项读取接口会过滤名称以 `Token`、`Secret`、`Key`、`secret` 或 `api_key` 结尾的敏感项，因此密码或密钥字段通常不会把现有明文重新显示出来，更换凭证时应明确输入新值。
- 选项修改会写入 `option.update` 管理日志，记录被修改的配置项名称，不记录配置值。这能帮助确认“谁修改了哪个键”，但不能用来恢复旧值，也不能代替外部密钥管理和变更记录。

<Callout type="warn">
  不要在截图、工单或普通日志中记录客户端密钥、SMTP Token、支付密钥等敏感值。读取接口不回显明文并不代表浏览器、代理、数据库备份或运维环境可以忽略凭证保护。
</Callout>

## 变更前记录与验证

系统设置当前没有统一的配置快照、历史版本比较或一键回滚功能。生产环境修改前应自行记录原值和验证结果，并准备按原配置逐项恢复。

建议至少记录以下信息：

- 修改的设置域、分区和字段；
- 修改前的非敏感值，以及敏感凭证在密钥管理系统中的版本；
- 预期影响的页面、接口、角色和外部服务；
- 测试步骤、通过标准和恢复条件；
- 多实例环境中预留的同步等待时间。

<Callout type="warn">
  页面中的“重置”不等于服务端快照或一键回滚。离开页面前重置通常只撤销未保存的输入；已经成功写入的配置必须再次提交原值才能恢复。
</Callout>

## 常见问题

- **访问 `/system-settings` 后进入系统信息**：这是默认重定向流程，不存在单独的概览编辑页。
- **Admin 能看到入口但访问失败**：系统设置要求 Root；侧边栏显示状态不会扩大角色或接口权限。
- **一次保存后只有部分字段变化**：多字段通常逐项提交。检查成功提示、刷新后的字段值和服务端日志，再单独处理失败项。
- **多节点表现暂时不一致**：等待选项同步周期，并检查各节点是否连接同一数据库、时间是否正常以及 `SYNC_FREQUENCY` 配置。
- **密钥字段为空**：敏感配置不会通过通用选项读取接口回显。更换密钥时重新输入，并按实际集成验证。
- **外部集成保存后仍失败**：保存不会测试所有连接。检查公网地址、回调、DNS、证书、网络、凭证权限和第三方服务日志。
- **需要恢复旧配置**：根据变更记录逐项填回原值；当前页面没有通用历史版本恢复功能。
