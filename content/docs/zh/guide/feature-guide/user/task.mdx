异步接口不会一直保持 HTTP 请求等待。服务端返回任务标识后，任务会在 `/usage-logs/task` 中显示。

## 查看任务

1. 打开控制台侧边栏的“任务日志”。
2. 在“绘图日志”和“任务日志”之间切换。
3. 按时间、状态或关键词筛选。
4. 打开任务查看参数、进度、结果和错误。

## 任务状态

任务可能经历 `pending`、`running`、`succeeded` 或 `failed`。失败时应先查看详情中的错误，再确认渠道、模型和系统任务是否正常。

<Callout type="info">
  异步任务的轮询和结算由系统任务处理。Root 可以在“系统信息”中查看相关任务是否正在运行。
</Callout>
