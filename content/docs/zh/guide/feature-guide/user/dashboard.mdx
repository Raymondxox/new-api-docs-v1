登录后进入 `/dashboard/overview`。概览页把创建 API 密钥、充值和发送首个请求串成快速开始流程，并显示当前的路由、认证、模型、余额和运行状态。

## 概览页

### 快速开始

1. 点击「创建 API 密钥」进入 `/keys`。
2. 在钱包中添加额度（如果启用了计费）。
3. 打开游乐场或使用其他客户端发送第一个请求。

![快速开始页](/assets/guide/feature-guide/overview-get-started.png)

### 用量与健康状态

页面会汇总近 24 小时消耗、历史消耗、请求数、剩余额度、成功率、平均延迟和吞吐量。

![概览信息页1](/assets/guide/feature-guide/overview-info-1.png)

### API 信息、公告、FAQ 和运行时间

![概览信息页2](/assets/guide/feature-guide/overview-info-2.png)

  这些卡片由 Root 在「系统设置」 → 「控制台内容」中配置。

## 数据看板

点击「数据看板」或访问 `/dashboard/models` 打开数据看板。

### 模型调用分析

按时间、模型和分组查看调用次数、Token、消耗和性能指标。

![数据看板信息页1](/assets/guide/feature-guide/dashboard-info-1.png)

### 分流

查看用户、密钥、分组、模型和渠道之间的请求流向，定位路由和计费问题。

![数据看板信息页2](/assets/guide/feature-guide/dashboard-info-2.png)

### 用户统计

管理员和 Root 可查看用户统计；普通用户不会显示管理视图。

![数据看板信息页3](/assets/guide/feature-guide/dashboard-info-3.png)
