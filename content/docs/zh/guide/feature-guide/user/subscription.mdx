---
title: 订阅计划
description: 浏览、购买和查看管理员发布的订阅套餐。
---

import { Callout } from 'fumadocs-ui/components/callout';

订阅计划位于钱包页面。只有管理员发布且当前用户可用的套餐才会显示。

## 浏览套餐

查看套餐价格、周期、额度、可用模型、分组和购买限制。套餐权益由管理员在订阅管理中定义。

## 购买订阅

1. 打开钱包中的订阅区域。
2. 选择套餐并查看权益。
3. 确认扣费方式和购买条款。
4. 完成支付或使用账户余额购买。

## 查看状态

页面会显示生效时间、到期时间、状态、剩余权益和自动续费信息。过期或被管理员下架的套餐不会继续接受新购买，但已有订阅的结算规则以实例配置为准。

<Callout type="warn">
  订阅和钱包的扣费顺序、预扣和退款规则由管理员配置；出现额度异常时请同时提供订阅详情和使用日志。
</Callout>
