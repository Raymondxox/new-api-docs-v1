title: 订阅计划
description: 浏览、购买和查看管理员发布的订阅套餐。
---

import { Callout } from 'fumadocs-ui/components/callout';

订阅计划位于钱包页面。只有管理员发布且当前用户可用的套餐才会显示。

## 浏览套餐

查看套餐标题、价格、有效期、额度、额度重置周期、购买限制和升级分组。额度为 0 的套餐可被配置为不限总额度，具体仍受套餐与模型规则限制。

## 购买订阅

1. 打开钱包中的订阅区域。
2. 选择套餐并查看权益。
3. 确认当前套餐允许的支付方式；部分套餐允许使用钱包余额兑换。
4. 完成支付后返回钱包并刷新订阅状态。

## 查看状态

页面会显示活动、已过期或已取消状态，以及结束时间、下次额度重置、总额度、已用额度和剩余额度。当前实现不会因为支付平台自动续费而自动延长 New API 权益；续购需要再次完成套餐购买流程。

用户可在钱包中选择以下计费偏好：

- 优先订阅
- 优先钱包
- 仅用订阅
- 仅用钱包

<Callout type="warn">
  套餐可以决定订阅额度耗尽后是否允许回退到钱包。计费偏好、套餐回退规则和剩余额度会共同影响请求是否能够继续扣费。
</Callout>
