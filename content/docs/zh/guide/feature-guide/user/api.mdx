## 游乐场

访问 `/playground`，选择当前账户可用的分组和模型，在输入框发送消息。游乐场使用登录会话调用内部 `/pg/chat/completions`，不需要手动粘贴 API 密钥。

### 发送请求

1. 选择分组和模型。
2. 按需启用温度、Top P、最大 Token、频率/存在惩罚和 Seed 等参数。
3. 输入消息并发送。
4. 查看流式回复、推理内容、工具调用或错误信息，并可复制、编辑、删除或重新生成消息。

如果没有可选模型，请检查当前分组、用户分组权限、可用渠道和模型限制。

## API 地址与认证

网关的 OpenAI 兼容地址通常为：

```text
http://your-host/v1
```

使用 API 密钥作为 Bearer Token：

```http
Authorization: Bearer sk-your-api-key
```

以聊天补全为例：

```bash
curl http://your-host/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-your-api-key" \
  -d '{"model":"gpt-4o-mini","messages":[{"role":"user","content":"你好"}]}'
```

## SDK 示例

### Python（OpenAI SDK）

```python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-api-key",
    base_url="http://your-host/v1",
)

response = client.chat.completions.create(
    model="gpt-4o-mini",
    messages=[{"role": "user", "content": "你好"}],
)
print(response.choices[0].message.content)
```

### 其他协议和端点

主站当前还注册了以下接口类别：

- `/v1/responses` 和 `/v1/responses/compact`
- `/v1/messages`（Claude 格式）
- `/v1beta/models/*`（Gemini 格式）
- `/v1/models`、`/v1/models/{model}` 和 `/v1beta/openai/models`（按认证头返回对应协议的模型列表）
- `/v1/alpha/search`（Codex 独立网页搜索格式）
- `/v1/images/generations`、`/v1/images/edits`
- `/v1/audio/transcriptions`、`/v1/audio/translations`、`/v1/audio/speech`
- `/v1/embeddings`、`/v1/rerank`、`/v1/moderations`
- `/v1/realtime` WebSocket

是否能成功调用取决于渠道类型、模型、映射和参数兼容性。使用 New API 向用户公开的模型名称，不要直接假设上游模型名可用。

`/v1/images/variations`、文件和旧版 fine-tunes 等路径虽然已注册，但当前明确返回“未实现”，不应视为可用兼容接口。

## 异步接口

视频、音乐、Midjourney 等接口可能创建异步任务。主站注册了 OpenAI 兼容视频端点、Kling、Jimeng、Suno 和 Midjourney 等路径；只有配置了对应渠道时才可用。请求返回任务标识后，到绘图日志或任务日志查看进度、结果和错误。

<Callout type="info">
  API 请求的实际计费、模型可用性、速率限制和参数兼容性由管理员的渠道、模型、分组和系统设置共同决定。
</Callout>
