## 游乐场

访问 `/playground`，在左侧选择模型，在输入框发送消息。游乐场使用当前账户可用的模型和额度。

### 发送请求

1. 选择模型或聊天预设。
2. 输入消息，按发送按钮提交。
3. 查看流式回复、工具调用或错误信息。

如果没有可选模型，通常是管理员尚未启用渠道、模型或分组。

## API 地址与认证

网关的 OpenAI 兼容地址通常为：

```text
http://your-host/v1
```

使用 API 密钥作为 Bearer Token：

```http
Authorization: Bearer sk-your-api-key
```

以聊天补全为例：

```bash
curl http://your-host/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-your-api-key" \
  -d '{"model":"gpt-4o-mini","messages":[{"role":"user","content":"你好"}]}'
```

## SDK 示例

### Python（OpenAI SDK）

```python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-api-key",
    base_url="http://your-host/v1",
)

response = client.chat.completions.create(
    model="gpt-4o-mini",
    messages=[{"role": "user", "content": "你好"}],
)
print(response.choices[0].message.content)
```

### Responses、Claude 和 Gemini

是否可用取决于管理员配置的渠道和模型。调用时使用页面显示的模型名称，不要直接把上游供应商的模型名当作平台模型名。

## 异步接口

绘图和部分媒体生成接口会创建异步任务。请求返回任务标识后，到“任务日志”查看状态、进度、结果和错误。

<Callout type="info">
  API 请求的实际计费、模型可用性、速率限制和参数兼容性由管理员的渠道、模型、分组和系统设置共同决定。
</Callout>
