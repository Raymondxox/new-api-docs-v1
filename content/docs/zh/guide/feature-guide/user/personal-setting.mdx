个人资料页地址为 `/profile`。页面显示用户名、用户 ID、角色、分组、余额、累计消耗和请求数，并提供账户绑定、通知与行为偏好、界面语言、安全、登录会话、个人侧边栏、Passkey、2FA，以及 Root 启用后的每日签到。

## 基本信息

查看并修改页面开放的账户字段。邮箱绑定或变更可能需要验证码，具体取决于实例的邮箱和身份验证配置。

## 密码和访问令牌

在安全区域更改密码、查看或生成访问令牌，并在实例允许时删除账户。访问令牌用于账户管理接口，与调用模型的 API 密钥不同，不应填入第三方 AI 客户端。

## 双因素认证（2FA）

1. 打开“设置与偏好 → 双因素认证”。
2. 点击“启用”，使用身份验证器扫描二维码。
3. 输入一次性验证码确认。
4. 保存备份码，并在需要时使用备份码恢复访问。

停用 2FA 或重新生成备份码前，需要完成当前账户验证。

## Passkey

如果 Root 已启用 Passkey，按页面提示注册浏览器、系统生物识别或安全密钥。注册和验证都依赖当前站点 Origin、RP ID 和浏览器的 WebAuthn 支持。

## 账户绑定

在「账户绑定」标签中绑定或解绑实例支持的 GitHub、Discord、OIDC、LinuxDO、Telegram、微信和自定义 OAuth 账号。解绑前请确保账户仍有密码、Passkey 或其他可用登录方式。

## 登录会话

查看当前设备和其他登录设备，撤销单个会话或点击「退出其他会话」。撤销当前会话会清除本地登录状态并跳转到登录页。

## 通知与行为偏好

在「设置与偏好」中选择额度告警通知方式并填写对应参数：

- 邮箱：可留空并使用账户邮箱
- Webhook：填写 URL 和可选密钥
- Bark：支持 `{{title}}`、`{{content}}` 模板变量
- Gotify：填写服务地址、应用 Token 和 0～10 的消息优先级

还可以设置额度告警阈值、是否接受未配置价格的模型，以及是否在使用/错误日志中记录请求 IP。Admin 和 Root 还可订阅定时上游模型检查的变化或失败摘要。

## 界面语言

界面语言会保存到账户设置并同步到已登录设备，同时影响控制台文本和 API 错误消息的语言。切换失败时页面会恢复到之前的语言。

## 个人侧边栏

如果 Root 没有关闭 `sidebar_settings` 权限，用户可以按区域隐藏或显示游乐场、聊天、数据看板、API 密钥、日志、钱包和个人资料等侧边栏模块。这里仅改变个人导航显示，不会授予新权限，也不会停用对应接口。

## 每日签到

Root 在「计费与支付 → 签到奖励」启用后，个人资料页会显示签到日历。每个账户每天只能签到一次，奖励从管理员设置的最小值和最大值之间产生，并直接增加主余额。页面可查看当月记录、累计签到次数和累计奖励；实例启用 Turnstile 时，签到可能要求先完成安全验证。

## 管理员控制的可见性

Root 的站点侧边栏配置决定模块是否允许显示，个人侧边栏只能在允许范围内进一步隐藏模块。某张卡片未显示时，应同时检查系统开关、账号权限和个人设置。
