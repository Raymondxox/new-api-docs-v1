个人资料页地址为 `/profile`，包含“账户绑定”和“设置与偏好”两个标签页。

## 基本信息

修改用户名、邮箱、语言和个人偏好。邮箱变更可能需要验证码，具体取决于实例配置。

## 密码和访问令牌

在安全设置中更改密码、生成访问令牌或删除账户。访问令牌用于管理账户相关 API 操作，与调用模型的 API 密钥不同。

## 双因素认证（2FA）

1. 打开“设置与偏好 → 双因素认证”。
2. 点击“启用”，使用身份验证器扫描二维码。
3. 输入一次性验证码确认。
4. 保存备份码，并在需要时使用备份码恢复访问。

停用 2FA 或重新生成备份码前，需要完成当前账户验证。

## Passkey

如果 Root 已启用 Passkey，点击“启用 Passkey”并按浏览器提示完成生物识别或安全密钥注册。Passkey 只在已注册的设备和 Origin 上可用。

## 账户绑定

在“账户绑定”标签中绑定或解绑实例支持的 OAuth、Telegram、微信等账号。解绑前请确保账户仍有其他登录方式。

## 登录会话

查看当前设备和其他登录设备，必要时撤销单个会话或退出其他会话。修改密码后，管理员也可能要求所有旧会话重新登录。

## 通知与侧边栏

根据实例开放的选项配置通知偏好和侧边栏模块显示。Root 可以在系统设置中控制这些模块是否可用。
