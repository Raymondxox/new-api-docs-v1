API 密钥页面地址为 `/keys`。当前版本的控制台名称是“API 密钥”，旧版本文档中的“令牌”均指同一类凭证。

## 创建 API 密钥

1. 打开“API 密钥”，点击“创建 API 密钥”。
2. 填写密钥名称，便于区分应用或环境。
3. 按需设置额度、过期时间、模型限制、IP 限制和分组。
4. 保存后立即复制完整密钥。完整密钥只在创建或主动查看时展示。

### 分组顺序

可以继承 Root 配置的 Auto 分组顺序，也可以为当前密钥设置自定义顺序。自定义顺序为空和继承全局顺序是两个不同状态。

### 常用限制

| 设置 | 作用 |
| --- | --- |
| 额度 | 限制该密钥可消耗的额度；留空或实例允许时可表示不限制 |
| 模型限制 | 只允许调用指定模型 |
| IP 限制 | 只允许来自指定 IP 或网段的请求 |
| 分组 | 决定可用渠道和计费倍率 |
| 过期时间 | 到期后拒绝使用该密钥 |

<Callout type="warn">
  API 密钥等同于密码。不要把完整密钥提交到代码仓库、截图、日志或聊天工具；怀疑泄露时立即删除并创建新密钥。
</Callout>

## 编辑和查看

在列表中打开行操作即可编辑名称、限制和分组。列表会显示状态、密钥前缀、额度、使用量、模型数、IP 限制和创建时间。

## 删除密钥

删除后，使用该密钥的客户端会立即收到认证失败。批量删除前请确认筛选结果，避免误删生产密钥。
