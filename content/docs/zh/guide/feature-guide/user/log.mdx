## 使用日志

访问 `/usage-logs/common` 查看通用 API 请求日志。普通用户默认只能查看自己的记录；管理员可按权限查看更多记录。

### 筛选记录

可按时间范围、模型、状态、请求类型、用户或渠道筛选。点击“展开”查看更多条件，点击“重置”清除筛选。

### 查看详情

打开一条记录可查看请求状态、模型、Token、耗时、消耗、错误信息和管理员可见的附加信息。敏感内容是否展示取决于实例日志策略。

## 绘图和任务日志

访问 `/usage-logs/task`，再切换“绘图日志”或“任务日志”。

- `pending`：等待执行
- `running`：执行中
- `succeeded`：成功
- `failed`：失败

任务日志用于追踪异步请求，不能用通用日志的成功状态替代任务最终状态。

## 与数据看板的关系

日志是明细数据，数据看板是聚合分析。新请求可能需要等待统计刷新后才出现在图表中。
