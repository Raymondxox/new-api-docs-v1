## 使用日志

访问 `/usage-logs/common` 查看通用 API 请求日志。普通用户只能读取自己的记录；Admin 和 Root 可按授权范围查看管理数据。

### 筛选记录

可按时间范围、模型、状态、请求类型等条件筛选。用户名、API 密钥名称、渠道等管理维度只会在当前账号有权限时出现。

### 查看详情

打开一条记录可查看请求状态、模型、Token、耗时、消耗、错误信息和管理员可见的附加信息。敏感内容是否展示取决于实例日志策略。

## 绘图和任务日志

使用日志是路径分区，而不是任务页内的标签：

- `/usage-logs/drawing`：Midjourney 等绘图任务
- `/usage-logs/task`：视频、音乐及其他异步任务

任务状态以页面实际值为准，常见状态包括 `NOT_START`、`SUBMITTED`、`QUEUED`、`IN_PROGRESS`、`SUCCESS`、`FAILURE` 和 `UNKNOWN`。

任务日志用于追踪异步请求，不能用通用日志的成功状态替代任务最终状态。

## 与数据看板的关系

日志是明细数据，数据看板是聚合分析。新请求可能需要等待统计刷新后才出现在图表中。
