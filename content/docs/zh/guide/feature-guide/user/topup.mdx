钱包页面地址为 `/wallet`。页面根据实例配置显示余额、累计消耗、请求数、充值、兑换码、订阅计划、推荐奖励和账单历史。

## 查看钱包

余额和额度的显示单位由 Root 的“计费与支付 → 货币与显示”设置决定。没有消费记录时，统计卡片可能显示 0。

## 在线充值

1. 在钱包中选择充值金额。
2. 选择实例启用的支付方式。
3. 确认订单并跳转到支付平台。
4. 支付完成后返回实例，等待订单状态更新。

可用支付方式由 Root 配置，当前主站支持的界面可能包括 EPay、Stripe、Creem、Waffo 和 Waffo Pancake 等网关。未配置的支付方式不会显示。

## 兑换码

1. 打开钱包的“兑换额度”。
2. 输入管理员提供的兑换码。
3. 点击兑换并确认余额更新。

兑换码通常只能使用一次，失效、已兑换或被禁用的兑换码不会增加额度。

## 推荐计划

在「推荐计划」中复制邀请码或邀请链接。满足实例规则后，奖励先进入推荐奖励余额；达到页面显示的最低金额后，可通过「转移奖励」转入主余额。

## 订单历史

账单历史可按订单号搜索并查看支付方式、金额、状态和时间。支付成功但余额未更新时，请保留订单号并联系管理员，不要重复支付。
