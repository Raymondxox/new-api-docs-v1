钱包页面地址为 `/wallet`。页面显示当前余额、累计消耗、请求数、订单历史、订阅和推荐计划。

## 查看钱包

余额和额度的显示单位由 Root 的“计费与支付 → 货币与显示”设置决定。没有消费记录时，统计卡片可能显示 0。

## 在线充值

1. 在钱包中选择充值金额。
2. 选择实例启用的支付方式。
3. 确认订单并跳转到支付平台。
4. 支付完成后返回实例，等待订单状态更新。

可用支付方式可能包括 EPay、Stripe、Creem、Waffo 或实例配置的其他网关。

## 兑换码

1. 打开钱包的“兑换额度”。
2. 输入管理员提供的兑换码。
3. 点击兑换并确认余额更新。

兑换码通常只能使用一次，失效、已兑换或被禁用的兑换码不会增加额度。

## 推荐计划

在“推荐计划”中复制邀请码或邀请链接。奖励金额、获得条件和转移方式由 Root 的额度设置决定。

## 订单历史

订单历史记录支付状态、金额和时间。支付成功但余额未更新时，请保留订单号并联系管理员，不要重复支付。
