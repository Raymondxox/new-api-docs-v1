New API 是一个统一的AI模型接口管理与分发系统，支持将多种大模型转为统一格式调用，支持OpenAI、Claude等格式，可供个人或者企业内部管理与分发渠道使用，并提供游乐场、OpenAI 兼容接口、模型与渠道路由、用量日志、计费、订阅和系统运维能力。本指南按角色分为用户指南与管理员指南两部分。

## 角色说明

平台根据账号角色控制菜单访问和操作权限，共分为三种角色：<br />普通用户：可以使用平台提供的个人功能。<br />管理员（Admin）：除个人功能外，还可以管理渠道、模型、用户以及计费运营。<br />超级管理员（Root）：拥有 Admin 的全部权限，并可额外查看系统信息、修改系统设置。

### 普通用户

注册后的默认角色，可访问游乐场、聊天预设、概览、数据看板、API 密钥、使用日志、任务日志、钱包、个人资料、模型广场和排行榜。<br />顶部导航、侧边栏和签到等入口受超级管理员（Root）配置控制。[查看设置文档 →](/zh/docs/guide/feature-guide/admin/settings-site)

### 管理员（Admin）

在普通用户权限基础上，Admin 默认可访问渠道、模型、用户、兑换码和订阅等管理资源。<br />渠道等资源还区分读取、操作、普通写入、敏感写入和查看密钥等动作，超级管理员（Root）可为管理员（Admin）账号设置权限覆盖以管理可用权限。[查看设置文档 →](/zh/docs/guide/feature-guide/admin/settings-site)

### 超级管理员（Root）

Root 拥有全部权限，额外可访问系统信息 `/system-info` 和系统设置 `/system-settings/site`。<br />系统设置当前分为站点与品牌、身份验证、计费与支付、模型与路由、安全与限制、控制台内容、运维七个设置域。

## 用户指南

适用于普通用户、Admin 和 Root，涵盖从注册、创建密钥到调用 API、查看日志和管理个人账户的流程。

### 注册与登录

支持账号注册、忘记密码重置、账号密码登录以及Passkey和多种第三方 OAuth 一键登录。

- 注册与登录
- Passkey和第三方 OAuth 登录
- 登录会话管理
- 忘记密码重置

[查看详细文档 →](/zh/docs/guide/feature-guide/user/auth)

### 概览与数据看板

概览页提供快速开始向导、API 请求示例、余额与用量摘要、性能健康、公告、FAQ 和运行状态。数据看板分为概览、模型调用分析、分流和管理员可见的用户分析。

- 创建 API 密钥、充值、发送首个请求
- 查看请求数、消耗、余额和性能健康
- 模型调用分析与分流关系
- 用户分析（普通用户不显示）

[查看详细文档 →](/zh/docs/guide/feature-guide/user/dashboard)

### 个人资料与安全

在个人资料页查看或管理账户信息、账户绑定、通知与行为偏好、界面语言、个人侧边栏、签到、2FA、Passkey、访问令牌和登录会话。

- 查看账户信息（名称、用户ID、剩余余额、总消耗额度、API请求数等信息）
- 管理账号绑定信息（邮箱或第三方OAuth账号）
- 设置通知和行为偏好
- 设置界面语言偏好
- 个人左侧边栏设置个性化显示
- 每日签到（若平台启用）
- 安全设置（更改密码、访问令牌、删除账户）
- 启用或禁用两步认证（2FA）
- 启用或禁用 Passkey 无密码登录
- 管理登录会话（查看会话、撤销会话）

[查看详细文档 →](/zh/docs/guide/feature-guide/user/personal-setting)

### API 密钥

API 密钥是调用网关 API 的凭证，可单独配置额度、过期时间、模型限制、分组、Auto 分组顺序、跨分组重试和 IP 白名单。

- 创建、编辑、删除和批量删除密钥
- 设置密钥名称、额度和过期策略
- 配置模型限制、IP 限制和用户分组
- 继承全局 Auto 分组顺序或设置密钥级顺序
- 查看密钥使用量并复制完整密钥

[查看详细文档 →](/zh/docs/guide/feature-guide/user/token)

### 使用 API 与游乐场

使用游乐场在线测试和体验 AI 模型；外部客户端可使用 OpenAI 兼容接口，也可按渠道配置调用 Claude、Gemini、Responses、图像、音频、嵌入和重排等端点。

- 在游乐场选择模型并发送请求
- 使用 API 密钥作为 Bearer 凭证
- 通过 OpenAI SDK、cURL 等方式调用
- 支持的接口端点

[查看详细文档 →](/zh/docs/guide/feature-guide/user/api)

### 聊天应用集成

手动将 API 地址和密钥配置到兼容客户端，或使用 Root 配置的网页、自定义协议和浏览器扩展聊天预设。具体可用模型和端点取决于管理员渠道配置。

- 获取统一 API 地址
- 配置 LobeChat、AionUI、CC Switch 等客户端
- 从左侧边栏 → 「聊天」 或 「API 密钥」菜单打开聊天预设
- 识别会向目标客户端传递完整密钥的预设
- 处理模型名称和路径兼容性
- 处理客户端对 Base URL、模型名和路径的差异

[查看详细文档 →](/zh/docs/guide/feature-guide/user/chat-apps)

### 使用日志与任务日志

使用日志页面包含通用日志、绘图日志和任务日志三个分区，记录请求、模型、状态、Token、耗时、错误和计费信息。

- 按权限查看自己的记录或管理范围内的记录
- 按时间、模型、状态和类型筛选
- 查看请求详情、错误和计费信息
- 查看绘图任务和异步任务进度

[查看详细文档 →](/zh/docs/guide/feature-guide/user/log)

### 钱包、充值与邀请

钱包显示余额、消耗、请求数、订单历史、订阅和推荐奖励。实例启用支付时可使用已配置网关充值，也可兑换管理员发放的兑换码并转移推荐奖励。

- 查看余额、消耗和账单历史
- 在线支付充值
- 兑换额度兑换码
- 查看推荐关系并将可用奖励转入主余额

[查看详细文档 →](/zh/docs/guide/feature-guide/user/topup)

### 订阅计划

在钱包中浏览管理员发布的订阅套餐。套餐可以包含额度、购买上限、额度重置周期以及升级/降级分组等权益。

- 浏览可用套餐
- 购买套餐并查看支付方式
- 查看生效、过期、取消和下次重置状态
- 选择钱包优先、订阅优先、仅钱包或仅订阅的计费偏好

[查看详细文档 →](/zh/docs/guide/feature-guide/user/subscription)

### 模型广场和排行榜

浏览平台已启用的 AI 模型的定价信息和状态;查看平台模型及供应商的使用量排名与变化趋势。

- 查看模型价格
- 搜索特定模型
- 了解计费规则

[查看详细文档 →](/zh/docs/guide/feature-guide/user/pricing)

### 异步任务

绘图、视频、音乐等异步生成请求会进入任务日志，用户可管理 Midjourney 绘图、Suno 音乐生成等异步任务。

- 查看任务和绘图日志
- 查看异步任务状态
- 异步任务接口

[查看详细文档 →](/zh/docs/guide/feature-guide/user/task)

## 管理员指南

适用于 Admin 和 Root。页面访问由角色基线和管理员权限矩阵共同决定；标有“Root 专属”的页面仅 Root 可见。

### 渠道管理

配置上游 AI 服务商、模型、密钥、分组和路由策略。

- 创建、编辑、复制和删除渠道
- 配置认证、Base URL、模型和分组
- 模型映射、参数覆盖和高级自定义路由
- 单 Key、批量建渠道和多 Key 渠道，支持随机或顺序轮询
- 单渠道、批量渠道测试、余额查询和上游模型同步
- 标签、批量启停、多 Key 管理、Codex 用量和失败自动禁用

[查看详细文档 →](/zh/docs/guide/feature-guide/admin/channel)

### 模型管理

模型页面分为“元信息”和“部署”两个标签。元信息维护模型和供应商信息；部署标签用于管理托管模型实例，需先在 Root 设置中启用部署服务。

- 添加、编辑、启用或停用模型元信息
- 同步上游模型和供应商元数据
- 管理模型状态、端点、分组、配额类型和官方同步标记
- 创建、更新配置、续期、重命名和删除部署
- 查看部署详情、容器、日志、状态、硬件和剩余时间

[查看详细文档 →](/zh/docs/guide/feature-guide/admin/model)

### 用户管理

查看用户列表并维护账户状态、角色、分组和额度。

- 搜索、筛选和查看用户
- 创建、编辑、禁用或删除用户
- 修改角色和分组
- 增加、扣减或覆盖用户额度
- 管理第三方绑定及管理员权限覆盖

[查看详细文档 →](/zh/docs/guide/feature-guide/admin/user)

### 兑换码管理

创建兑换码、复制选中代码、编辑状态、启用/禁用、删除单个代码，以及批量清理已使用、已禁用和已过期代码。

[查看详细文档 →](/zh/docs/guide/feature-guide/admin/redemption)

### 订阅管理

创建、编辑和启停订阅套餐，设置价格、额度、周期、额度重置、购买上限、升级/降级分组和支付配置，并查看用户订阅。

[查看详细文档 →](/zh/docs/guide/feature-guide/admin/subscription)

### 分组与计费

分组不是独立侧边栏页面，而是由 Root 分组价格、渠道、用户和 API 密钥共同维护的路由与计费维度。

- 创建和维护分组
- 配置模型倍率和分组倍率
- 分配渠道和用户可用分组
- 设置全局 Auto 分组顺序和跨分组重试

[查看详细文档 →](/zh/docs/guide/feature-guide/admin/group)

### 日志与数据分析

管理员可按授权范围查看通用、绘图和任务日志，并在数据看板查看模型调用、分流和用户分析。

- 按时间、用户、模型、渠道和状态筛选
- 查看请求详情、错误和管理员信息
- 查看模型调用分析和全站消耗趋势

[查看详细文档 →](/zh/docs/guide/feature-guide/admin/log)

### 系统信息与任务（Root 专属）

系统信息页显示实例节点、在线/失效状态、角色、版本、运行时、资源和最近心跳；系统任务区域显示跨实例维护任务、执行进度、执行器、更新时间和错误，活动任务会自动刷新。

[查看详细文档 →](/zh/docs/guide/feature-guide/admin/system-info)

### 系统设置（Root 专属）

系统设置按照当前控制台拆分为七个设置域。每个设置域的保存结果会影响整个平台，请在生产环境修改前备份并验证。

- 站点与品牌
- 身份验证
- 计费与支付
- 模型与路由
- 安全与限制
- 控制台内容
- 运维

[查看详细文档 →](/zh/docs/guide/feature-guide/admin/system-setting)
