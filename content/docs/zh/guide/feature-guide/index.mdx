New API 是一个统一的AI模型接口管理与分发系统，支持将多种大模型转为统一格式调用，支持OpenAI、Claude等格式，可供个人或者企业内部管理与分发渠道使用，并提供游乐场、OpenAI 兼容接口、模型与渠道路由、用量日志、计费、订阅和系统运维能力。

本指南按使用边界分为用户指南、管理员指南和系统设置指南三部分。本文描述项目支持的功能；某个实例中是否显示或可用，还取决于当前账户角色、系统配置、渠道与模型配置以及外部服务状态。

## 角色与访问边界

平台有普通用户、管理员（Admin）和超级管理员（Root）三种角色。菜单是否显示与实际访问权限不是同一件事：系统设置可以控制入口的可见性，后端接口仍会按账户角色和具体权限检查请求。

### 普通用户

普通用户使用实例开放的个人功能，例如游乐场、聊天预设、概览、数据看板、API 密钥、日志、钱包和个人资料。顶部导航、侧边栏模块和签到等入口由 Root 配置；用户还可能在全局允许范围内调整个人侧边栏。

### 管理员（Admin）

Admin 在个人功能之外，可以管理渠道、模型、用户、兑换码和订阅等 Admin 范围的资源。当前只有渠道使用细粒度权限目录：普通 Admin 的默认基线包含 `read`、`operate` 和 `write`，默认不包含 `sensitive_write` 和 `secret_view`。Root 可以为具体 Admin 配置渠道权限覆盖；其他管理页面仍以 Admin 角色检查为主。

### 超级管理员（Root）

Root 拥有全部渠道权限，并可使用 Root 专属的系统信息、系统任务和系统设置。涉及选项、密钥、支付、认证、外部服务和实例运维的改动会影响整个实例，应在生产环境先记录原值并验证影响范围。

适用于普通用户、Admin 和 Root，覆盖从注册、创建 API 密钥、调用模型到查看日志和管理个人账户的常用流程。

### 概览与数据看板

从概览页完成快速开始、查看余额和用量摘要，并在数据看板查看请求、模型调用、分流及按权限开放的用户分析。

创建和维护调用网关 API 的凭证，并按需设置额度、有效期、模型限制、分组、Auto 分组顺序、跨分组重试和 IP 白名单。

### 使用 API 与游乐场

使用游乐场测试已开放模型，或通过 API 密钥调用 OpenAI 兼容接口及实例支持的其他模型端点。

将 API 地址和密钥配置到兼容客户端，或使用 Root 配置的网页、自定义协议和浏览器扩展聊天预设。可用模型和端点取决于实例中的渠道配置。

### 日志与异步任务

查看使用日志、绘图日志和异步任务记录，并按当前权限范围筛选请求、计费、错误、状态和结果。管理员查看管理范围内记录的方式也由本页说明。

[查看详细文档 →](/zh/docs/guide/feature-guide/user/log)

### 钱包与订阅

集中管理余额、在线充值、兑换码、订单、邀请奖励、订阅计划和计费偏好。支付方式、金额、折扣、奖励、套餐和计费规则均由实例配置决定。

[查看详细文档 →](/zh/docs/guide/feature-guide/user/wallet)

### 模型广场和排行榜

浏览实例已开放的模型定价和状态，并查看模型及供应商的用量排名与变化趋势。

[查看详细文档 →](/zh/docs/guide/feature-guide/user/pricing)

## 管理员指南

适用于 Admin 和 Root，包含六个日常管理页面。系统级选项另归入后面的系统设置指南；其中系统信息为 Root 专属。

### 渠道管理

配置上游 AI 服务商渠道、认证信息、模型、分组和路由可靠性策略，并执行测试、余额刷新、模型同步和批量操作。

[查看详细文档 →](/zh/docs/guide/feature-guide/admin/channel)

### 模型管理

维护模型元信息、名称匹配、供应商和官方同步；在部署服务已由 Root 配置时，也可管理托管模型部署。

[查看详细文档 →](/zh/docs/guide/feature-guide/admin/model)

### 用户管理

查看和维护用户账户、状态、角色、分组、额度、登录绑定、安全凭证和订阅。

[查看详细文档 →](/zh/docs/guide/feature-guide/admin/user)

### 兑换码管理

创建、查看、编辑、启用、禁用和清理额度兑换码。

[查看详细文档 →](/zh/docs/guide/feature-guide/admin/redemption)

### 订阅管理

发布和维护订阅套餐，管理用户订阅权益、额度周期、分组升级与回退。

[查看详细文档 →](/zh/docs/guide/feature-guide/admin/subscription)

### 系统信息（Root 专属）

查看实例节点状态、资源指标和后台系统任务，并处理失联实例记录。

[查看详细文档 →](/zh/docs/guide/feature-guide/admin/system-info)

分组是渠道、用户、API 密钥和计费配置共同使用的路由与计费维度，不再作为独立主导航项。日志、绘图记录和用户异步任务的查看方式请参阅[日志与异步任务](/zh/docs/guide/feature-guide/user/log)。
