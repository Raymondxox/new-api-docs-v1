New API 是一个统一的AI模型接口管理与分发系统，支持将多种大模型转为统一格式调用，支持OpenAI、Claude等格式，可供个人或者企业内部管理与分发渠道使用，并提供 Playground、用量分析、计费、路由和运维管理等能力。本指南按角色分为用户指南与管理员指南两部分。

![系统首页](/assets/guide/home.png)

## 角色说明

平台根据账号角色控制菜单访问和操作权限，共分为三种角色：<br />普通用户：可以使用平台提供的个人功能。<br />管理员（Admin）：除个人功能外，还可以管理渠道、模型、用户以及计费运营。<br />超级管理员（Root）：拥有 Admin 的全部权限，并可额外查看系统信息、修改系统设置。

### 普通用户

注册后的默认角色，可访问游乐场、概览、数据看板、API 密钥、使用日志、任务日志、钱包和个人资料。用户只能查看自己的用量、密钥和账户信息。

### 管理员（Admin）

在普通用户权限基础上，可访问渠道、模型、用户、兑换码和订阅管理，并可在数据看板和日志中查看管理范围内的平台数据。

### 超级管理员（Root）

在 Admin 权限基础上，额外拥有系统信息、系统任务和系统设置权限。系统设置包含站点与品牌、身份验证、计费与支付、模型与路由、安全与限制、控制台内容、运维七个设置域。

## 用户指南

适用于所有已登录用户，涵盖从注册到日常使用的完整流程。

### 注册与登录

支持账号注册、忘记密码重置、账号密码登录以及Passkey和多种第三方 OAuth 一键登录。

- 注册与登录
- Passkey和第三方 OAuth 登录
- 登录失败和会话限制处理
- 忘记密码重置

[查看详细文档 →](/zh/docs/guide/feature-guide/user/auth)

### 概览与数据看板

概览页提供快速开始向导、API 请求示例、余额与用量摘要、路由状态、公告、FAQ 和运行状态。数据看板提供模型调用分析、分流分析；管理员还可查看用户统计。

- 创建 API 密钥、充值、发送首个请求
- 查看请求数、消耗、余额和性能健康
- 模型调用分析与分流关系
- 管理员用户统计

[查看详细文档 →](/zh/docs/guide/feature-guide/user/dashboard)

### 个人资料与安全

在个人资料页管理账户信息、账户绑定、通知偏好、2FA、Passkey、访问令牌和登录会话。

- 修改用户名、邮箱和密码
- 启用或停用双因素认证（2FA）
- 注册 Passkey 无密码登录
- 绑定或解绑第三方账号
- 查看并撤销登录会话
- 生成访问令牌或删除账户

[查看详细文档 →](/zh/docs/guide/feature-guide/user/personal-setting)

### API 密钥

API 密钥是调用网关 API 的凭证，可单独配置额度、模型、分组和来源限制。

- 创建、编辑、删除和批量删除密钥
- 设置密钥名称、额度和过期策略
- 配置模型限制、IP 限制和用户分组
- 使用 Auto 分组顺序或自定义分组顺序
- 查看密钥使用量并复制完整密钥

[查看详细文档 →](/zh/docs/guide/feature-guide/user/token)

### 使用 API 与游乐场

游乐场用于在线选择模型、发送消息和验证路由；外部客户端使用兼容 OpenAI 的接口，也可按实例支持情况调用 Claude、Gemini 等格式。

- 在游乐场选择模型并发送请求
- 从概览或系统设置获取 API 地址
- 使用 API 密钥作为 Bearer 凭证
- 通过 OpenAI SDK、cURL 等方式调用
- 查看支持的端点和异步任务接口

[查看详细文档 →](/zh/docs/guide/feature-guide/user/api)

### 聊天应用集成

将 API 地址和密钥配置到兼容 OpenAI API 的聊天客户端。具体可用模型和端点取决于管理员渠道配置。

- 获取统一 API 地址
- 配置 LobeChat、ChatGPT Next Web 等客户端
- 处理模型名称和路径兼容性
- 使用自定义客户端参数覆盖

[查看详细文档 →](/zh/docs/guide/feature-guide/user/chat-apps)

### 使用日志与任务日志

使用日志记录 API 请求、模型、状态、Token 和计费信息；任务日志单独展示绘图和异步任务。

- 查看全部或仅自己的记录
- 按时间、模型、状态和类型筛选
- 查看请求详情、错误和计费信息
- 查看绘图任务和异步任务进度

[查看详细文档 →](/zh/docs/guide/feature-guide/user/log)

### 钱包、充值与邀请

钱包显示余额、消耗、请求数、订单历史和推荐奖励。实例启用支付时，可使用配置的支付网关充值；也可兑换管理员发放的兑换码。

- 查看余额、消耗和账单历史
- 在线支付充值
- 兑换额度兑换码
- 查看推荐关系和奖励

[查看详细文档 →](/zh/docs/guide/feature-guide/user/topup)

### 订阅计划

在钱包中浏览管理员发布的订阅套餐，购买后按套餐规则获得模型或额度权益，并查看当前订阅状态。

- 浏览可用套餐
- 购买或续订套餐
- 查看生效、过期和取消状态
- 根据实例配置选择钱包或订阅优先扣费

[查看详细文档 →](/zh/docs/guide/feature-guide/user/subscription)

### 定价

定价页展示实例公开的模型、分组和计费信息。实际价格由管理员配置的倍率、工具价格和计费模式决定。

- 搜索和筛选模型
- 查看输入、输出、缓存和图片等价格
- 对比不同分组的可用性和倍率

[查看详细文档 →](/zh/docs/guide/feature-guide/user/pricing)

### 异步任务

绘图和其他异步生成请求会进入任务日志，用户可查看任务状态、进度、结果或错误。

- 查看任务和绘图日志
- 查看 pending、running、succeeded、failed 状态
- 阅读任务详情和错误信息

[查看详细文档 →](/zh/docs/guide/feature-guide/user/task)

## 管理员指南

适用于 Admin 和 Root。带有“Root 专属”的页面只有超级管理员可见。

### 渠道管理

配置上游 AI 服务商、模型、密钥、分组和路由策略。

- 创建、编辑、复制和删除渠道
- 配置认证、Base URL、模型和分组
- 模型映射、参数覆盖和高级自定义路由
- 多 Key 管理、轮询和 Key 统计
- 单渠道、批量渠道测试和余额查询
- 标签、批量启停和失败自动禁用

[查看详细文档 →](/zh/docs/guide/feature-guide/admin/channel)

### 模型管理

模型页面分为“元信息”和“部署”两个标签。元信息用于维护模型能力和价格，部署用于管理托管模型实例（需先启用部署服务）。

- 添加、编辑、启用或停用模型元信息
- 同步上游模型元数据
- 配置模型价格、倍率、工具价格和分组可用性
- 创建、编辑、续期和删除模型部署
- 查看部署容器、日志、硬件和地域

[查看详细文档 →](/zh/docs/guide/feature-guide/admin/model)

### 用户管理

查看用户列表并维护账户状态、角色、分组和额度。

- 搜索、筛选和查看用户
- 创建、编辑、禁用或删除用户
- 修改角色和分组
- 增加、扣减或覆盖用户额度
- 管理第三方绑定

[查看详细文档 →](/zh/docs/guide/feature-guide/admin/user)

### 兑换码管理

批量生成、导出、启用、禁用和删除额度兑换码，并查看兑换状态。

[查看详细文档 →](/zh/docs/guide/feature-guide/admin/redemption)

### 订阅管理

创建和发布订阅套餐，设置价格、周期、额度、模型和分组权益，并查看用户订阅。

[查看详细文档 →](/zh/docs/guide/feature-guide/admin/subscription)

### 分组与计费

通过用户分组控制渠道可用性、倍率、自动分组和差异化计费。

- 创建和维护分组
- 配置模型倍率和分组倍率
- 分配渠道和用户可用分组
- 设置 Auto 分组顺序和自动分组规则

[查看详细文档 →](/zh/docs/guide/feature-guide/admin/group)

### 日志与数据分析

管理员可查看全站 API、绘图、任务和操作日志，并在数据看板分析模型、用户、渠道和分流关系。

- 按时间、用户、模型、渠道和状态筛选
- 查看请求详情、错误和管理员信息
- 查看模型调用分析和全站消耗趋势

[查看详细文档 →](/zh/docs/guide/feature-guide/admin/log)

### 系统信息与任务（Root 专属）

系统信息页显示当前实例、版本、运行时、CPU、内存、存储和最近心跳；系统任务区域显示维护任务、执行进度、执行器和错误，并在任务运行时自动刷新。

[查看详细文档 →](/zh/docs/guide/feature-guide/admin/system-info)

### 系统设置（Root 专属）

系统设置按照当前控制台拆分为七个设置域。每个设置域的保存结果会影响整个平台，请在生产环境修改前备份并验证。

- 站点与品牌
- 身份验证
- 计费与支付
- 模型与路由
- 安全与限制
- 控制台内容
- 运维

[查看详细文档 →](/zh/docs/guide/feature-guide/admin/system-setting)
